# 图库

顶栏 **图库** 和 **首页 / 指南 / 参考** 是同级入口：任意文档页都能点进来，再点 **首页** 就回到文档。

配方跑出来的图 / 视频 / 3D 不进 git。源数据在私有 Hugging Face 数据集 [`seachen/modal-comfyui-picture`](https://huggingface.co/datasets/seachen/modal-comfyui-picture)。GitHub Actions **每小时**（也可手动）拉取后编进本页。GLB / GLTF 在浏览器里预览（拖动旋转）；每个合集分页，离开视口的 3D 会卸掉 WebGL，避免以后作品多了把页面撑死。
